Paste guard demo

This page runs the extension's real src/guard.js, unmodified. The box below stands in for an AI tool's prompt box. Paste the vectors, watch the overlay, and watch the report panel: detection happens entirely in this page, and the report never contains what you pasted.

And the negatives

These must paste through silently: a date like 12-03-24, a phone number, a 16-digit order number that fails the Luhn check, an email signature with a lowercase "this email is confidential" footer, ordinary prose using the word "internal".

The full detector list and the deliberate exclusions are documented in src/guard.js. Deploying the real thing is covered in the README next to this folder.
